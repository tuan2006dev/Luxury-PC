# Thư mục chứa mô hình 3D (.glb / .gltf) của LuxuryPC

Thư mục này được thiết lập để bạn thả các mô hình 3D linh kiện PC tự vẽ từ Blender vào đây.

## Hướng dẫn đặt tên file mô hình:
Sau khi vẽ và xuất file `.glb` từ Blender, bạn hãy lưu file vào đây và đặt tên tương ứng để chuẩn hóa code:

1. **Vỏ máy (Case)**: `case.glb`
2. **Bo mạch chủ (Mainboard)**: `mainboard.glb`
3. **Bộ vi xử lý (CPU)**: `cpu.glb`
4. **Tản nhiệt (Cooler)**: `cooler.glb`
5. **Bộ nhớ RAM**: `ram.glb`
6. **Card đồ họa (GPU)**: `gpu.glb`
7. **Bộ nguồn (PSU)**: `psu.glb`

*Lưu ý: Đảm bảo xuất file dưới định dạng `.glb` (glTF Binary) để tải nhanh nhất trên trình duyệt.*
